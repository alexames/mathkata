API Reference    {#mathkata_api_reference}
=============

This document describes all classes, functions, macros and files that make
up the [MathKata][] library.  This is intended to be used as a reference for
C++ programmers who are familiar with [geometry][], [vectors][], [matrices][],
[quaternions][] and [linear algebra][].

The API reference is broken into the following sections:
   * [Build Configuration](@ref mathkata_build_config)
      - Describes configuration options for [MathKata][] code generation.
   * [Allocators](@ref mathkata_allocator)
      - Allocators to simplify the process of memory allocation for [MathKata][]
        data structures.
   * [Constants](@ref mathkata_constants)
      - Constants to use in conjunction with [MathKata][] classes.
   * [Vectors](@ref mathkata_vector)
      - Class and functions to manipulate [vectors][].
   * [Matrices](@ref mathkata_matrix)
      - Class and functions to manipulate [matrices][].
   * [Quaternions](@ref mathkata_quaternion)
      - Class and functions to manipulate [quaternions][].
   * [GLSL Mappings](@ref mathkata_glsl)
      - Mappings to GLSL data types and functions.
   * [Utility Functions](@ref mathkata_utilities)
      - Variety of useful functions that can be used with
        [Vector](@ref mathkata::Vector) and [Matrix](@ref mathkata::Matrix)
        classes.
   * [Version Constants](@ref mathkata_version)
      - Constants which identify the library version.

   [MathKata]: @ref mathkata_overview
